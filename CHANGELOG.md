# Changelog

## 1.3.0
- Force: 8 Q-Links follow the page. Play: tap Quick Edit or Sound (Volume, Sound Select, Reverb, Delay) to pick what they
  control; Browse: one Preset knob; FX: tap Effect 1 or Effect 2. Sound picks are slowed so the knob doesn't race.
- Force: changing sounds no longer flashes the Q-Link screens over to the FX page.
- Effects you switch off stay off when you change sounds; FX Q-Links move every effect setting (small ranges too).
- Installs the Akai SDK way: unzip into `VST2 Plugins` on your drive (one folder for 32- and 64-bit units).
- Reads your M1 ROMs from `Content/ROMs` when it starts (no ROM data in the plugin any more), so it can be released as a
  normal download. Same sound as 1.2.0: every table and all 200 factory sounds render bit-identically.
- Without ROMs: silent, display says NO M1 ROMS; settings are still kept.
- New Library bank **Fullban / Preview**: ten original programs.
